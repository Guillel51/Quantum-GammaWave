# v1.9.0 — estado

Fase 4/9 (comparación de presets en el instrumento). Una función nueva que no duplica nada de lo que ya había.

## Qué se construyó

| pieza | dónde | qué hace |
|---|---|---|
| referencia automática | `core.h` `snd_clean` → `pc_arm` | cada carga de preset, guardado de usuario, recall de proyecto / sección y UNDO deja el sonido como referencia |
| arranque | `ui_input.c` `ui_notices` (`snd_first`) | el sonido del encendido también es referencia |
| slot | `ui.c` `pc_orig` (**en `.lowbuf`**) | un solo `track_t` en RAM; ningún preset en flash, ningún formato tocado |
| intercambio | `ui.c` `pc_compare` → `ab_swap` | el A/B que ya existía; los dos lados existen siempre, el ISR nunca ve medio sonido |
| control | `ui_layer.c` capa de EDIT, tecla **A3** | `A/B` (y `PRESET` mientras suena el preset); una tecla cada vez |
| indicador | `ui_draw.c` pie, `ui_homeviews.c` HOME | `nombre A` el preset tal cual, `nombre*` la edición |

El A/B manual (HOME, EDIT mantenido = `ab_store`) se queda donde estaba y no se toca. En Web Studio no hay A/B de
presets que duplicar: `web/*.js` solo compara paquetes y huellas.

## Hallazgo

El toque de EDIT en HOME que el A/B manual esperaba **no llega a su bloque**: la capa se queda el toque (tras él el
instrumento está en la página de EDIT y el pie dice `HOLD [EDIT] QUICK`). Por eso el control nuevo vive en la capa
de EDIT. No se movió ni se quitó el bloque de HOME.

## Pruebas

`tests/ui_test` — cinco checks nuevos, todos en verde:

1. valores: una tecla pone el preset, la siguiente devuelve la edición, valor por valor (tabla entera comparada);
2. motor: ANALOG ↔ LOFI, ida y vuelta;
3. FM6: parche y valores cambian de lado juntos;
4. una pista sin referencia propia no se compara por error (`pc_side` 0 y la tecla no hace nada);
5. la tecla real: EDIT mantenido + A3 abre la capa, dice `PRESET (A)` y devuelve la edición intacta.

Barrido de UI: 196 pantallas × 22 paletas, 0 hallazgos de lint, 0 alineaciones fuera de 1 px, 0 tintas sobre su
propio color (3 839 888 medidas). Base de píxeles: **128 fotogramas cambiados** (48 por el texto de versión, 80 por
la celda `A/B` de la capa de EDIT), 0 perdidos, 0 nuevos.

Coste de la función, símbolo a símbolo (`build/felucca.syms` contra `HEAD`): +728 B de código y +60 B de
constantes. Con `-Oz` y LTO ya en uso (`tools/build.py`) no quedan banderas que recuperen 736 B. La deuda queda
medida y anotada para la fase de tamaño.

## Límite

Todo es host x86-64 y emulador. **No hay ninguna medida en la FM-1 física** (escribir en la unidad está prohibido
en este repositorio): ni tiempos, ni comportamiento del panel, ni ausencia de clics en el DAC real.
