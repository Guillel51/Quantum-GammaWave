## Bloqueos concretos

1. **Sin navegador real:** Web Studio no se puede abrir ni capturar aquí. La sintaxis se comprobó con
   `node --check`; la interacción y el canvas no están verificados en navegador.
2. **Sin FM-1:** no se probaron LCD, encoder, audio, USB/MIDI, JEDEC, backup ni recuperación USB_KEY.
3. **Sin ALSA Sequencer:** el host no tiene `/dev/snd/seq`; `python-rtmidi` falla con
   `ALSA lib seq.c:935:(snd_seq_open_noupdate) Unknown SEQ default`. La instalación simulada no sustituye
   una instalación real.
4. **SWEEP:** no cabe como tecla dentro de los 32 bits actuales de `PF_*`; su DSP de filtro sigue accesible
   por LPF/HPF y KNOB 1, pero no hay tecla SWEEP. Está documentado en `docs/PUNCH_IN_FX_AUDIT.md`.
