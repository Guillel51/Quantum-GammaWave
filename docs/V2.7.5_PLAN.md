## 2. Expansión Sonora — 8 Motores

### 2.1 ANALOG (expansión)
**Funciones nuevas:**
- Suboscilador: 2do oscilador corporal
- PWM: modulación de duty cycle
- Sync: modulación por espejado
- Unison ligero: 2 voces con desplazamiento
- Drive: saturación variable (implica DIST)
- Filtros: LPF, BPF, HPF con Q

### 2.2 FM6 (expansión)
**Funciones nuevas:**
- Feedback: delay interno entre operadores
- Algoritmos: 8 configuraciones de topología
- Ratios: 23 bandas de ratio
- Envolventes por operador: A, B, C, D, E, F
- Brillo: intensity de cada operador
- Metalización: brightness de cada operador

### 2.3 PHASE (expansión)
**Funciones nuevas:**
- Profundidad: depth de modulación
- Feedback: delay de fase
- Movimiento estéreo: stereo spread
- Morphing: morph entre formas

### 2.4 LOFI (expansión)
**Funciones nuevas:**
- Bit depth: degradación por cuantificación
- Sample rate: reducción
- Degradación: tritado
- Saturación: drive
- Texturas: mosaico, pixels

### 2.5 VOICE (formant)
**Funciones nuevas:**
- Formantes: F1, F2, F3
- Vocales: voz natural
- Resonancia: formant shifting
- Transiciones: glide entre vocales

### 2.6 WHEEL (expansión)
**Funciones nuevas:**
- Curvas: mapping de parámetros
- Rangos: ranges asignables
- Polaridad: polaridad de eje
- Destinos asignables: mapear a cualquier parámetro

### 2.7 NOISE (expansión)
**Funciones nuevas:**
- Colores de ruido: white, pink, brown
- Filtros: LPF, HPF con Q
- Resonancia: resonance
- Modulación: LFO de color

### 2.8 DRUM-X (expansión)
**Funciones nuevas:**
- Pitch: pitch de cada sample
- Decay: decay de cada sample
- Transient: ataque
- Cuerpo: body
- Ruido: nivel de ruido
- Tono: tone
- Edición individual del kit
