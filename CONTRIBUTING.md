# Contributing to Pocket GammaWave (GW-1)

Thanks for helping! Pocket GammaWave (GW-1) is a custom firmware for the FM-1, based on Felucca by Leo Kuroshita (Hügelton Instruments).
Please report Pocket GammaWave's bugs and ideas here, not to Felucca: Pocket GammaWave's changes are not theirs to answer.

| What | Where |
|---|---|
| A bug you can reproduce | [Quantum GammaWave Issues](https://github.com/Guillel51/Quantum-GammaWave/issues/new): one issue per bug |
| A feature idea or request | [Quantum GammaWave Issues](https://github.com/Guillel51/Quantum-GammaWave/issues/new) with "idea" in the title |
| How to use it, or how something works | the [manual](docs/MANUAL.md) ([español](docs/MANUAL.es.md)), then an issue if it is still unclear |
| Forks, mods, music, demos | an issue or a message to the author: we love to see them |

## Reporting a bug

Please include the Pocket GammaWave version (hold HOME > ABOUT), your computer's OS and browser if the editor or installer is
involved, the steps to reproduce it, what you expected and what happened. A photo or a short video helps.

## Pull requests

Pull requests are welcome, including AI-assisted ones, with the same bar for all:

- keep it small and focused on one thing;
- make sure you understand the change and can explain it;
- test it on a real FM-1;
- run `tests/run_tests.sh` (see [BUILDING.md](BUILDING.md));
- new files carry the GPL-3.0-only SPDX header.

By contributing you agree that your contribution is licensed under GPL-3.0-only.

Felucca itself, its web editor and its installer live at [hugelton/Felucca](https://github.com/hugelton/Felucca) and
[hugelton/Felucca-WebApp](https://github.com/hugelton/Felucca-WebApp); report there only what also happens on
Felucca's own firmware.
